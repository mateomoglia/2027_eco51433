Data visualisation

This part covers the main graph types in Stata. Part of the material is adapted from this Princeton tutorial. Variable names of the online datasets follow the original files and should be checked with describe.

General remarks

The standard syntax of a graph command is graph_command variable, options. Several plots are overlaid with twoway, for instance a bar chart and a line, or a scatter plot and a fitted line:

twoway (graph_command1 var1, options1) (graph_command2 var2, options2), general_options

twoway can be abbreviated tw. The options placed inside a parenthesis apply to one plot. The options placed after the last parenthesis apply to the whole graph.

Good practice for graphs:

  • Label the axes with the variable and its unit
  • Include a legend when several series are shown, and omit it otherwise
  • Keep one message per graph and limit the amount of information
  • Use colours that remain readable in black and white and for colour-blind readers

Schemes

A scheme defines the general look of a graph. The list of official schemes is documented here. The package blindschemes adds schemes with colour-blind safe palettes, such as plotplain and plottig.

ssc install blindschemes, replace
set scheme plotplain

Export

A graph is exported with graph export. The vector format .pdf is preferred for LaTeX documents.

graph export "$path/output/figures/my_graph.pdf", replace
graph export "$path/output/figures/my_graph.png", replace width(2000)

Scatter plots

The command is scatter, abbreviated sc. It requires two variables, y then x, in this order. We use trade data for the year 2012.

use "https://dss.princeton.edu/training/wdipol.dta", clear
keep if year == 2012

scatter import export            // Levels: the graph is hardly readable

generate limport = log(import)   // Logarithms improve readability
generate lexport = log(export)

We now choose the colour, the symbol and the width of the symbol, and label the axes.

scatter limport lexport, ///
    mcolor(cranberry) msymbol(Oh) mlwidth(0.1) ///
    xtitle("Exports (USD, log)") ytitle("Imports (USD, log)")

The same graph with abbreviated options:

sc limport lexport, mc(cranberry) m(Oh) mlw(0.1) xti("Exports (USD, log)") yti("Imports (USD, log)")

Abbreviations are convenient when exploring the data. Complete options are preferred in a do-file.

Markers can be labelled with the option mlabel(). The labels are readable only for a small number of observations.

scatter limport lexport if inlist(country, "France", "Germany", "Italy", "Spain"), ///
    mcolor(cranberry) mlabel(country) mlabposition(3)
TipExercise

  2. Give the line the same colour as the points
  3. Adapt the legend with the option order(), and place it at the bottom
NoteSolution 
twoway (scatter limport lexport, mcolor(cranberry) msymbol(Oh) mlwidth(0.1)) ///
       (lfit limport lexport, lcolor(cranberry)), ///
    xtitle("Exports (USD, log)") ytitle("Imports (USD, log)") ///
    legend(pos(6) cols(2) order(1 "Countries" 2 "Linear fit"))

The option pos(6) places the legend at 6 o’clock, that is, below the graph. The order of the plots in the command determines their number in order().

Histograms and bar charts

Histograms

Histograms are produced with histogram, abbreviated hist. We use the full panel of countries.

use "https://dss.princeton.edu/training/wdipol.dta", clear

hist gdppc
hist gdppc, frequency
hist gdppc, kdensity
hist gdppc, kdensity normal

The legend of this latter graph is hardly customisable. Building the graph with twoway gives full control. The global histopts groups the options of the histogram.

global histopts "bin(20) fcolor(ebblue%60) lcolor(white)"

quietly summarize gdppc, detail
local mu = r(mean)
local sigma = r(sd)
local lo = r(p1)
local hi = r(p99)

twoway (hist gdppc, $histopts) ///
       (kdensity gdppc, lcolor(cranberry)) ///
       (function y = normalden(x, `mu', `sigma'), range(`lo' `hi') lcolor(navy)), ///
    xtitle("GDP per capita (USD)") ///
    legend(pos(6) cols(2) order(2 "Kernel density" 3 "Normal distribution"))

The distributions of two groups are compared by overlaying two histograms, with the alternative || syntax of twoway. Here, we compare the distribution of GDP per capita across countries in 1990 and in 2012.

twoway hist gdppc if year == 1990, bin(10) || ///
       hist gdppc if year == 2012, bin(10) fcolor(none) lcolor(red) ///
    legend(label(1 "1990") label(2 "2012"))

Bar charts

The command graph bar (vertical) and graph hbar (horizontal) plot statistics of a variable. The syntax over() plots a statistic for each category of a variable.

sysuse auto, clear
graph bar (mean) price, over(foreign)

We now plot the GDP per capita of the wealthier countries. The selection is based on the average over the period. A selection based on gdppc > 18000 would instead select observations, not countries.

use "https://dss.princeton.edu/training/wdipol.dta", clear

bysort country: egen gdppc_avg = mean(gdppc)

graph hbar (mean) gdppc if gdppc_avg > 18000, ///
    over(country, sort(1) descending label(labsize(*0.7))) ///
    bar(1, color(ebblue))

graph hbar (mean) gdppc (median) gdppc if gdppc_avg > 18000, ///
    over(country, sort(1) descending label(labsize(*0.8))) ///
    legend(label(1 "Mean") label(2 "Median")) ///
    bar(1, color(navy)) bar(2, color(cranberry))

Box plots

generate lgdppc = log(gdppc)
generate ltrade = log(trade)

graph box lgdppc ltrade

Line charts

Line charts are appropriate for time series and panel data. The years are on the x-axis and the values on the y-axis. We use the built-in life expectancy dataset.

sysuse uslifeexp, clear

line le year                        // The variable on the y-axis is placed first
line le_male le_female year         // Several series: the x variable is always last

An alternative uses scatter with the option connect().

scatter le_male le_female year, connect(l l) msymbol(none none)

We improve the graph in three ways: the legend is placed inside the plot region, the lines are restyled and an annotation is added. We first change the legend and the titles.

line le_male le_female year, ///
    legend(ring(0) pos(5) region(lstyle(none))) ///
    title("{bf:Life expectancy} in the 20th century") ///
    xtitle("Year") ytitle("Years") ///
    note("Source: US Census Bureau") ///
    ylabel(, nogrid) xlabel(, nogrid)

The option ring(0) places the legend inside the plot region and pos(5) at 5 o’clock. The grid is removed by nogrid and the title is in bold thanks to {bf: }.

The lines are restyled with lcolor() and lpattern():

line le_male le_female year, ///
    lcolor(green cranberry) lpattern(longdash longdash_dot) ///
    legend(ring(0) pos(5) region(lstyle(none))) ///
    title("{bf:Life expectancy} in the 20th century") ///
    xtitle("Year") ytitle("Years") ///
    note("Source: US Census Bureau") ///
    ylabel(, nogrid) xlabel(, nogrid)

The drop of life expectancy in 1918 is due to the Spanish flu. We add an arrow with pcarrowi y1 x1 y2 x2 (clockposition) "label". It goes from the point \((x_1, y_1)\) to the point \((x_2, y_2)\).

twoway (line le_male le_female year, ///
            lcolor(green cranberry) lpattern(longdash longdash_dot)) ///
       (pcarrowi 45 1930 40 1918 (2) "Spanish flu", ///
            color(black) mlabcolor(black)), ///
    legend(order(1 2) ring(0) pos(5) region(lstyle(none))) ///
    title("{bf:Life expectancy} in the 20th century") ///
    xtitle("Year") ytitle("Years") ///
    note("Source: US Census Bureau") ///
    ylabel(, nogrid) xlabel(, nogrid)

The option order(1 2) keeps only the two lines in the legend and excludes the arrow.

Regression coefficients

Regression coefficients are plotted with their confidence intervals using the package coefplot. Part of the material is adapted from this blog post.

ssc install coefplot, replace

We use the auto dataset. The variables are rescaled between 0 and 1, so that their coefficients are comparable. A loop avoids repeating the same code.

sysuse auto, clear

foreach v in mpg weight length {
    quietly summarize `v'
    generate `v'_01 = (`v' - r(min)) / (r(max) - r(min))
}

A standardised variable (mean 0 and standard deviation 1) is obtained with egen mpg_std = std(mpg).

We run a regression and plot its coefficients. coefplot uses the last estimation by default.

regress price mpg_01 weight_01 length_01 i.foreign, vce(robust)
coefplot
Tip

Estimates stored with eststo can be used directly: coefplot m1. They can be restored with estimates restore m1, which is also useful to access the e() results.

The graph is improved step by step. The names of the coefficients are printed by regress, coeflegend.

regress, coeflegend      // Print the names to use in the options of coefplot

* Vertical line at zero and removal of the constant
global coefplotopts "drop(_cons) xline(0, lcolor(red) lwidth(medium))"

coefplot, $coefplotopts ///
    coeflabels(mpg_01 = "MPG" weight_01 = "Weight" length_01 = "Length")

* A more complete model
regress price mpg_01 weight_01 length_01 i.foreign i.foreign#c.mpg_01, vce(robust)

coefplot, $coefplotopts ///
    coeflabels(mpg_01 = "MPG" weight_01 = "Weight" length_01 = "Length" ///
               1.foreign = "Foreign" 1.foreign#c.mpg_01 = "MPG X Foreign")

* Final version
coefplot, $coefplotopts ///
    xtitle("{bf:Effect on vehicle price (USD)}") ///
    graphregion(margin(medsmall)) ///
    xlabel(, nogrid) ///
    ylabel(, glpattern(dash) glcolor(gs14)) ///
    coeflabels(mpg_01 = "MPG" length_01 = "Length" weight_01 = "Weight" ///
               1.foreign = "Foreign" 1.foreign#c.mpg_01 = `""MPG X" "Foreign""') ///
    headings(mpg_01 = "{bf:Vehicle specs}" ///
             1.foreign = "{bf:Production info}" ///
             1.foreign#c.mpg_01 = "{bf:Interactions}", gap(0))

Several models are compared in the same graph. Each model is stored and passed in a parenthesis, with its own label.

eststo clear
eststo m1: regress price mpg_01 weight_01 length_01, vce(robust)
eststo m2: regress price mpg_01 weight_01 length_01 i.foreign, vce(robust)

coefplot (m1, label("Baseline")) (m2, label("With origin")), ///
    keep(mpg_01 weight_01 length_01) xline(0) legend(pos(6) cols(2))

The confidence level is chosen with levels(), and several levels are plotted at once with levels(95 90).
